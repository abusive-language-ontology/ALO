Ontology Specification

Abstract

The ontology of abusive speech is designed for publishing results of the abusive language annotation process in a structured form. The goal is to have a placeholder for different dataset formats, to support diverse abusive language detection methodologies and content providers.

Introduction back to ToC

ALO (Abusive Language Ontology) is a domain ontology designed to support the semantic representation of abusive language and related annotation and analysis information. It provides a structured conceptual model for representing abusive language categories, targets, linguistic and rhetorical phenomena, annotations, analyses, and provenance-related information. ALO supports the representation and semantic linking of information associated with abusive language resources, including annotated textual content and lexical information. The ontology distinguishes between abusive language as a conceptual phenomenon and its textual realizations and supports the representation of different abuse categories and target types. It also provides concepts and relations for describing annotation and analysis activities and their results. Abuse categories and target types are represented as OWL classes, enabling their organization into class hierarchies and further specialization within the ontology. ALO reuses selected PROV-O classes for provenance-related aspects of annotation and analysis. This reuse allows provenance information to be represented using an established Semantic Web vocabulary while ALO provides the domain-specific semantics required for abusive language representation. The ontology is intended to facilitate the semantic representation, integration, querying, and reuse of abusive language information in Linked Data and knowledge graph environments. Although its initial development and application are centered on Serbian abusive language resources, the conceptual model does not impose language-specific restrictions.
