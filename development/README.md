# Ontology Development Artefacts

This directory contains supporting artefacts produced during the
development of the ALO ontology.

## Information Gathering

The `information-gathering` directory contains the materials used during
the information-gathering and elicitation phase of ontology development.

## Term Registry

The `term-registry` directory contains the term registry used during the
conceptualization and initial structuring of ALO.

The original development artefacts are provided in Microsoft Excel
format. CSV versions are additionally provided to facilitate access,
inspection, and reuse without requiring proprietary spreadsheet software.
