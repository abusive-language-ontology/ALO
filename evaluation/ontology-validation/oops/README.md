# OOPS! Ontology Evaluation

The ALO ontology was evaluated using OOPS! (OntOlogy Pitfall Scanner!).

The initial evaluation identified ontology modelling pitfalls that were
reviewed during ontology refinement. In particular, P29 and P31 resulted
in modifications to the ontology. After these modifications, ALO was
evaluated again using OOPS!.

This directory contains:

- `oops_initial_report.pdf` — report produced before ontology refinement.
- `oops_final_report.pdf` — report produced for the final version of ALO.
